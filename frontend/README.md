# frontend

Widoki aplikacji zbudowane na Bootstrapie 5.3, uzupełnione własnymi stylami i skryptami JavaScript.

| Plik | Do czego służy |
| --- | --- |
| `login.html` | Logowanie i rejestracja |
| `boards.html` | Lista tablic, dodawanie, edycja i usuwanie tablicy |
| `board.html` | Tablica z trzema kolumnami, filtry i okno (modal) zadania |
| `css/style.css` | Własne kolory, czcionka, wygląd kolumn i kart zadań |
| `js/api.js` | Wspólne funkcje: zapytania `fetch` do API, komunikaty, błędy formularzy |
| `js/login.js`, `js/boards.js`, `js/board.js` | Logika poszczególnych widoków |
